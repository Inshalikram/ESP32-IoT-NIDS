⚡

LightGBM Classifier

Gradient boosting model trained on CIC-IoMT 2024. Handles class imbalance via SMOTE oversampling. Deployed via Flask REST API.

🧬

TFLite / TinyML

Quantized neural network compiled to .tflite, loaded onto ESP32-S3 tensor arena. ~2ms inference latency per packet with confidence threshold tuning.

📦

Custom Dataset

Real WiFi packets captured with ESP32 in promiscuous mode. 7 injected Layer 2 attack types (KRACK, deauth floods, beacon spam, etc.) on local testbed.

🔔

MQTT Alert Pipeline

On detection, ESP32 publishes alert payloads via MQTT broker. Dashboard receives HTTP POST with attack type, confidence score, frame metadata, and timestamp.
